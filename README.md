# Killer for Zed

A high-contrast dark theme for [Zed](https://zed.dev), ported from the [Killer VSCode theme](https://marketplace.visualstudio.com/items?itemName=AustinBillings.killer-theme).

Coral keywords, teal types, warm amber numbers. Designed for long sessions on a dark display.

## Variants

- **Killer Dark**

## Install

### From the Zed extension registry

In Zed: `cmd-shift-p` → `zed: extensions` → search for **Killer** → Install.

### As a dev extension

Clone this repo, then in Zed: `cmd-shift-p` → `zed: install dev extension` → point at the cloned directory.

Activate via `cmd-k cmd-t` and pick **Killer Dark**.
